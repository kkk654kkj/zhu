猪专属播放器 使用说明（v1.6.0）
==============================

一、怎么启动
------------
· 双击桌面上的「猪专属播放器」快捷方式即可。
· 如果快捷方式被删了：进本文件夹（D:\猪专属播放器），双击「启动播放器.vbs」。
· 不要直接双击「猪专属播放器.exe」——本机 Windows 环境下 Chromium 沙箱起不来，
  直接双击会“闪一下就没了”。启动器会自动补上 --no-sandbox 参数（只关闭渲染沙箱，
  程序不联网，只读你本机的音乐文件）。

二、为什么放在 D:\猪专属播放器
------------------------------
· 之前放在 D:\文档\deepseek-harness\default-workspace\ 下面，双击会弹「安全警告：
  未知发布者」。原因是那个工作区目录被设成了「低完整性级别」，Windows 认为里面的
  程序不可信。换任何程序进去都会弹，不是本程序的问题。
· 所以成品挪到了 D:\猪专属播放器，放在这一层就正常了，不再弹窗。
· 如果想换位置：整个文件夹一起拷走就行（绿色便携），但别放回那个 default-workspace
  目录，也别放在 C:\Windows、C:\Program Files 这类需要管理员权限的地方。

三、第一次用
------------
· 默认曲库目录是 D:\音乐，首次启动会自动扫描一次。
· 支持格式：flac / mp3 / m4a / aac / wav / ogg / opus / ape / wma / aiff / dsf / dff / mka。
· 歌词：与音频同名、扩展名 .lrc 的文件会被自动读取（UTF-8 / GBK 都能识别）。
  文件名没带歌手、或者写成「歌手 - 歌名」的情况，会用 LRC 里的 [ti:] / [ar:] 校正。
· 封面：优先读音频内嵌封面；没有内嵌时找同名图片，或「专辑__ALBUM.jpg」
  「歌手__ARTIST.jpg」这类命名。

四、音乐文件夹管理（v1.1 新增）
-------------------------------
点右上角「音乐文件夹与扫描」按钮（文件夹图标）打开管理弹窗：
· 上方列出当前所有曲库目录，每个目录右侧的 × 可以移除。
· 点「+ 添加文件夹」可以再选一个目录加入（支持一次多选，会自动去重）。
· 确认无误后点「保存并扫描」，会立刻按新目录重建曲库，弹窗自动关闭。
· 支持多个文件夹同时作为曲库，子文件夹会被递归扫描。
· 改目录不会丢收藏/歌单：它们按歌曲记录，重新扫到同一首就还在。

五、界面
--------
左栏：全部音乐 / 我的收藏 / 最近播放 / 专辑 / 我的歌单（点 + 新建）。
中间：歌曲列表，点表头可排序，双击表头恢复默认顺序，右键有菜单。
右侧：封面 + 同步滚动的歌词，点歌词任意一行可跳转到那一句。
底部：播放条（进度、上一首/播放/下一首、音量、播放模式）。
搜索：右上角搜索框，歌名/歌手/专辑/文件名都能搜，**也支持拼音**——
      输 zjl 或 zhoujielun 都能找到周杰伦（v1.6 新增）。
拖拽：按住歌曲左侧的序号，拖到左边的歌单上就能加进歌单；
      播放队列面板里的条目可以上下拖动排序（v1.6 新增）。

六、快捷键
----------
空格            播放 / 暂停
← / →           快退 / 快进 5 秒（按住 Shift 是上一首 / 下一首）
↑ / ↓           音量 +/-
M               静音
L               收藏当前歌曲
Ctrl + F        搜索框
Esc             关闭右键菜单 / 关闭弹窗
（以上在窗口内有效）

另外注册了系统级媒体键：键盘上的播放/暂停、上一首、下一首、停止键，以及
Ctrl+Alt+空格（播放暂停）、Ctrl+Alt+←/→（切歌）、Ctrl+Alt+↑/↓（音量）、
Ctrl+Alt+D（桌面歌词）、Ctrl+Alt+M（迷你模式），窗口在后台时也能用。

七、播放模式
------------
点底部那个循环图标切换：列表循环 → 单曲循环 → 随机播放 → 顺序播放。
切歌和暂停都有 0.35 秒淡入淡出（可在 data\settings.json 改 fadeMs）。

八、音量均衡（v1.2 新增）
------------------------
· 播放条右侧的均衡器图标（三条竖线）是音量均衡开关。打开后，各首歌会自动调整到
  差不多的响度，不再出现「这首歌特别小、下一首突然炸」的情况。
· 第一次使用：右键均衡器按钮 →「分析曲库响度」。程序会把曲库里的歌逐首解码分析
  （71 首大约 1 分钟），分析结果保存在本地，之后随时开关。
· 右键菜单里还能改「目标响度」（默认 -16 LUFS，数字越小整体越响）和清除分析数据。
· 某首歌觉得还是太轻/太响：在歌曲列表里右键它 →「音量增益」，手动 -6 ~ +6 dB。
  手动设置永远生效（即使没开均衡开关），选「0 dB（重置）」可还原。
· 说明：分析在播放的同时也能跑；ape / wma / dsf 这类格式系统解码不了会自动跳过。

九、桌面歌词（v1.2 新增）
------------------------
· 点标题栏的「桌面歌词」按钮（或按 Ctrl+Alt+D、托盘菜单里选）打开：一个透明的
  悬浮窗，始终显示在屏幕最前面，跟着播放进度滚动当前句，下面带一句预览。
· 鼠标移上去会浮出控制条：🔒 锁定 / A- A+ 字号 / 🎨 换颜色 / ✕ 关闭。
· 锁定后窗口完全不吃鼠标（可以点它下面的东西）；解锁点主窗口标题栏那个按钮即可。
· 位置拖一拖就行，窗口大小也能拉；位置、字号、颜色都会记住，下次打开还是老样子。
· 关掉主程序时桌面歌词会一起关掉（不会有孤零零的歌词窗留在桌面上）；
  下次启动如果之前开着，会自动恢复。

十、均衡器与频谱（v1.3 新增）
----------------------------
· 播放条右侧的滑条图标（三条横杠加旋钮）打开均衡器面板，靠右悬浮在播放条上方。
· 10 段 EQ：31 / 62 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz，范围 ±12dB。
  拖动滑块即时生效；双击某个滑块把它归零。
· 8 个预设：平直 / 流行 / 摇滚 / 古典 / 爵士 / 低音增强 / 人声 / 电子。点一下就套用。
· 面板右上角「已开启 / 已关闭」是总开关。关闭后所有频段归零（原声），但设置会记住。
· 动任意滑块会自动打开均衡器，不需要先按开关。
· 为了避免加强低音后爆音，程序会自动把整体音量往回收（内部自动前级，不需要手动调）。
· 频谱：右侧歌词面板封面下面那条跳动的柱状图，就是当前音乐的实时频谱，
  跟着节拍动，峰值会缓慢下落。不需要可以忽略，不影响任何功能。

十一、迷你模式（v1.4 新增）
--------------------------
· 进入：点标题栏右侧的「迷你模式」按钮（一个方框里套小方框的图标），或者在任何
  界面下按 Ctrl+Alt+M，托盘图标右键菜单里也有「迷你模式」。
· 窗口会缩成一张竖向小卡片（约 320×420），里面只有：封面、歌名、歌手、当前一句
  歌词、进度条、上一首/播放/下一首、播放模式、收藏。窗口能拖到屏幕任意角落。
· 播放不会中断，也不会重开窗口——迷你模式只是把同一个窗口变小、换一套界面，
  所以不会出现「切来切去歌断了」的情况。
· 返回完整模式：点卡片右上角的放大按钮，或再按一次 Ctrl+Alt+M，
  也可以直接双击封面/歌名那一块。窗口会回到你进迷你之前的尺寸和位置
  （如果当时是最大化，回来也还是最大化）。
· 卡片大小可以自己拉（最小约 300×360），下次进迷你还是这个尺寸；
  迷你卡片里的进度条同样可以拖动跳转。
· 关掉程序时如果正处在迷你模式，下次启动还是迷你卡片。

十二、数据存在哪
--------------
全部在本文件夹的 data 子目录里，纯绿色便携版，拷走整个文件夹就能带走配置：
  data\settings.json   设置、收藏、播放历史、歌单、播放次数
  data\library.json    曲库缓存（文件名、元数据、时长、封面路径）
  data\covers\         从音频里提取出来的封面图
  data\lx-player.log   启动日志（出问题时看这个）

十三、常见问题
------------
Q: 双击快捷方式弹「安全警告：未知发布者」
A: v1.1.2 已解决。旧版成品放在 default-workspace 那个目录里，该目录是「低完整性
   级别」，Windows 对里面的程序一律提示。现在成品在 D:\猪专属播放器，不会再弹。

Q: 双击没反应 / 闪一下就退出
A: 用「启动播放器.vbs」或桌面快捷方式启动。直接跑 猪专属播放器.exe 会因为沙箱
   问题秒退。

Q: 换音乐目录 / 多加几个文件夹
A: 点右上角的文件夹图标，在弹窗里增删目录后点「保存并扫描」。

Q: 扫描完歌曲数不对
A: 点右上角文件夹图标重新扫描；只认上面列出的音频扩展名，子文件夹也会递归扫描。

Q: 歌词不滚动 / 对不上
A: 右下的两个小箭头可以调歌词偏移（每次 0.5 秒），A- / A+ 调字号。
   v1.1.2 已修：旧版歌词面板设了「平滑滚动」，高亮每 0.2 秒切一次会把动画反复打断，
   结果卡在半路不回来。现已改为瞬时定位，当前句稳定停在面板正中；
   只有歌曲开头几句和结尾几句滚到边界时无法居中，属正常。

Q: 封面变成空白 / 不显示
A: v1.1.2 已修。旧版把封面图路径按「绝对路径」记在缓存里，整个文件夹一搬家就全部
   失效。现在改成记相对文件名，整个文件夹拷到哪都能正常显示。

Q: 点了歌名却切不过去 / 还是上一首
A: v1.1 已修。旧版在播放中点击同列表的其它歌曲时，会把播放位置强行拉回当前歌曲。

Q: 歌词显示的是别的歌
A: v1.1 已修。旧版快速连续切歌时，上一首的歌词可能晚到并覆盖新歌的歌词。

Q: 每次启动都自动重新扫描曲库？
A: 默认不开。想开的话：先把全部程序关掉，再用记事本打开 data\settings.json，把
   "settings" 里的 "autoScanOnStart" 从 false 改成 true（注意不要动其它内容），
   保存后重新启动。开着的代价是每次启动多等几秒；关掉它还是老样子。
   v1.3.1 已接线：这个开关以前只是个摆设，现在真的会生效。

Q: 想让点 × 时最小化到托盘（不退出）
A: 右下角托盘图标右键 → 勾选「关闭时最小化到托盘」（v1.3.1 新增开关）。

Q: 想换背景色 / 主题色
A: 目前是固定的深色主题（主题色 #31c27c），要改可以编辑源码里的 css 后重新打包。

Q: 迷你模式怎么回不到原来的大小
A: 正常情况点放大按钮（或 Ctrl+Alt+M、双击封面）就会回到进迷你前的尺寸位置。
   如果之前手动拉过迷你卡片，回来的还是完整模式原来那个尺寸——两者分别记忆。

Q: Ctrl+Alt+M 没反应
A: 这个组合键可能被别的软件占用了（例如某些截图/录屏工具）。改用标题栏的迷你
   按钮，或者托盘右键菜单里的「迷你模式」即可。

Q: 桌面歌词关掉再打开，歌词要等一下（或暂停一下）才出来
A: v1.4.1 已修。旧版歌词窗口是异步加载的，打开那一瞬间的歌词会被丢掉，而程序
   又按「内容没变就不发」去重，所以只能等下一句切歌时才出现（暂停会让播放状态
   变化，恰好触发一次重发）。现在主进程会记住当前歌词行，窗口一就绪立刻补上。

Q: 鼠标移到桌面歌词上会闪一下
A: v1.4.2 已修。旧版悬停时控制条会挤进布局里，把歌词整体往下推 16px（移开又弹
   回去），看起来就是闪；另外背景颜色也会随悬停变化，整窗重绘更容易看出来。
   现在控制条是浮在上方的一条小面板（淡入淡出、不占位），背景不再变化，
   歌词位置全程不动。

Q: 开了播放器以后，浏览器/微信/视频都没有声音了
A: 说明你开着「独占输出」，它按设计独占了声卡（v1.5 新增功能）。点标题栏那个
   波形按钮关掉即可；也可以先暂停播放，声卡就还给其他程序了。

十五、独占输出（位完美，v1.5 新增）
----------------------------------
先说结论：这个功能只影响"数字信号到声卡这一段"，不改变文件本身。

· 开关在哪：标题栏右侧那个"波形"图标（喇叭上面有高低柱子），右键不用，
  单击即可开关。第一次开启会弹一个确认框，把下面这些副作用讲清楚。
· 开启后：改用 mpv + Windows WASAPI 独占输出。声卡会按文件的**原生采样率、
  原生位深**直接接收数据——44.1k/16bit 的歌就是 44100Hz/16bit 送出去，
  96k 的歌就是 96000Hz 送出去，中间不做重采样、不做软件音量（音量 100% 时）。
· 怎么看是不是真的位完美：播放条右侧会出现一个小标签，
  绿色「位完美 · 48k/32bit」= 正按原生格式直出；
  琥珀色「非位完美 · 音量 82%」= 你把音量拖下来了，软件在改样本值；
  琥珀色「已重采样」= 声卡不接受这个采样率，程序只能重采样；
  琥珀色「已回退共享」= 独占打不开（被别的程序占用/驱动不支持），已自动退回普通输出。
· 开启独占期间，**其他程序会没有声音**（浏览器、微信、视频都静音）——这是
  WASAPI 独占的固有行为，不是故障。关掉独占或暂停播放后恢复正常。
· 独占模式下，均衡器、音量均衡、手动音量增益、实时频谱会自动禁用
  （任何软件处理都会破坏位完美）。播放模式、歌词、桌面歌词、迷你模式一切照常。
· 切换开关时界面会重新加载一次，播放会中断，但队列、进度、播放模式都会恢复。
· 如果想在独占模式下调音量：拖音量条可以（会显示"非位完美"），
  或者在功放/系统音量上做，播放器保持 100% 才是原样输出。
· 指定输出设备（v1.6 新增）：如果你接了 USB DAC / 外置声卡，默认设备未必是它。
  **右键**标题栏的波形按钮（或右键播放条右侧那个位完美标签），会列出所有
  WASAPI 输出设备，点一个即可。正在独占播放时切换会自动重启引擎并回到原位置；
  没在播放时切换只是记住选择，下次开启独占生效。选「跟随系统默认设备」可以还原。

十六、v1.6 新增的几件事
------------------------
【拼音搜索】搜索框支持全拼与首字母：zjl / zhoujielun / 周杰伦 都能出结果。
   拼音是在扫描曲库时算好存起来的，搜起来不卡。改了歌名要重新扫描才会更新。

【歌单文件（m3u / m3u8）】
   · 导出：在左边「我的歌单」里右键某个歌单 → 「导出为 m3u…」。
     默认存成相对路径（歌单和音乐放在一起时，整个文件夹搬走也不会失效）；
     跨盘保存时会自动写成完整路径。
   · 导入：点「我的歌单」标题右边那个文件夹图标 → 选一个 .m3u / .m3u8。
     程序会按路径去曲库里找对应的歌，找到的直接建成新歌单；
     不在曲库里的条目会被跳过，并在提示里告诉你有几条没匹配上。

【断点续播】只对**超过 10 分钟**的音轨生效（有声书、讲座、现场、交响乐）。
   听到一半切走或关掉程序，下次再点这首会从断点继续，屏幕上会提示
   「已从 XX:XX 继续播放」。普通歌曲不记位置，避免点播放却从中间开始。
   快听完（剩 20 秒内）会清掉断点，下次从头放。

【拖拽】队列面板里拖动条目可以排序（正在播的那首不会因为拖动而串位）；
   歌曲列表里按住序号拖到左边歌单上，直接加进那个歌单。

【任务栏按钮】鼠标悬停在任务栏图标上，会出现 上一首 / 播放暂停 / 下一首 三个按钮。
   注意：这只是任务栏的缩略图工具栏，**不是**系统媒体控制中心，
   所以系统音量浮层、锁屏界面里暂时还看不到歌名和封面。

【看不见的修复】
   · 以前拔掉移动硬盘（或网络盘掉线）再点扫描，库里这些歌会被当成"已删除"清空，
     重连后要重新扫很久。现在检测到目录不可访问会跳过清理，只提示「N 个目录不可访问」。
   · 个别文件解析失败（例如驱动不支持的 wma），以前会悄悄从列表里消失；
     现在扫描结束会告诉你有几个解析失败。
   · 程序被任务管理器强杀后，后台可能残留 mpv 进程占着声卡（表现为别的程序全没声音）。
     现在下次启动会自动清掉残留的 mpv。
   · data 文件夹里的浏览器缓存会自动清理，不会越用越大。

十四、关于
--------
自制的本地音乐播放器，界面参考洛雪音乐助手（lx-music）的布局。
Electron 38 + music-metadata（+ pinyin-pro 做拼音搜索），完全离线，不联网、不上传任何数据。
（v1.5 起额外带一个 mpv 引擎，只在打开「独占输出」时使用。）
v1.1   更新：修复点击切歌失效、歌词错配，新增音乐文件夹管理。
v1.1.1 更新：改名为「猪专属播放器」，换用自制的小猪图标，启动器同步改名。
v1.1.2 更新：成品移出低完整性工作区，放到 D:\猪专属播放器，双击不再弹安全警告。
             修复搬动文件夹后封面全部空白（封面路径改为相对存放）。
             修复歌词滚动卡在半路不动（去掉 CSS 平滑滚动，改瞬时定位）。
v1.2.0 更新：新增音量均衡（自动分析曲库响度、逐曲归一，可手动 ±dB 微调）；
             新增桌面歌词浮窗（透明置顶、可锁定穿透、字号/颜色可调）。
v1.3.0 更新：新增 10 段均衡器（8 个预设、±12dB、自动防削波）与实时频谱；
             关闭主程序时桌面歌词窗口一起关闭。
v1.3.1 更新：托盘菜单新增「关闭时最小化到托盘」开关（点 × 收到托盘不再退出）；
             「启动时自动重扫曲库」开关接线生效（settings.json 的
             autoScanOnStart）；
             曲库缓存的封面路径改为相对存放并自动归一化，整个文件夹
             搬家后封面不再失效。
v1.4.0 更新：新增迷你模式（同一窗口缩成竖向小卡片：封面/歌名/歌手/当前歌词/
             进度/播放控制/收藏；标题栏按钮、Ctrl+Alt+M、托盘菜单三个入口；
             双击封面返回；尺寸与形态分别记忆）。
v1.4.1 更新：修复「桌面歌词关掉再打开，要暂停一下才显示歌词」——歌词窗口是异步
             加载的，打开瞬间推送的歌词会被丢掉，且之后内容没变就不再重发。
             现在主进程会缓存最近一次歌词行，窗口就绪时立即补发。
v1.4.2 更新：修复「鼠标移到桌面歌词上会闪一下」——旧版鼠标一悬停，控制条会挤进
             布局，把歌词整块往下推 16px，移开又弹回去；同时悬停还会改变整窗
             背景透明度，触发全窗口重绘。现在控制条改成悬浮层（不占布局、淡入
             淡出），背景保持恒定，歌词位置不再抖动。
v1.5.0 更新：新增「独占输出（位完美）」——用一个随包附带的 mpv 引擎
             （engine\mpv.exe）走 Windows WASAPI 独占，把 FLAC 等按文件
             原生采样率/位深直接送声卡（实测 44.1k/16、48k/32、96k/32 均
             不重采样）。标题栏波形按钮开关，播放条右侧标签实时显示
             「位完美 / 非位完美 / 已重采样 / 已回退共享」。独占期间
             EQ、音量均衡、手动增益、频谱禁用（软件处理会破坏位完美），
             其他程序会暂时没有声音；独占失败会自动回退共享输出。
v1.6.0 更新：搜索支持拼音与首字母；歌单可导入/导出 m3u、m3u8；超过 10 分钟的音轨
             记住播放位置；队列可拖拽排序、歌曲可拖进歌单；独占输出可指定具体
             声卡设备（右键波形按钮）；任务栏缩略图增加上一首/播放/下一首。
             另修复：拔盘后扫描会清空曲库、解析失败的文件静默消失、快速连点
             播放/暂停会自己停下、淡入期间拖音量被拉回。
