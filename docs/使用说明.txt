=============================================
入口：左侧栏最上面的「在线音乐 → 在线搜索」。

怎么用
------
· 输入「歌名」或「歌名 歌手」（例：起风了 买辣椒也用券），回车或点「搜索」。
· 同时搜酷我 / 网易云 / QQ音乐 / 酷狗，每家 30 条，结果里带彩色「音源」标签。
  点源名可以关掉某个源（至少留一个）。
· 双击一行播放，或点行尾 ▶；「+」是加入当前播放队列；「↓」是下载到本地。

下载管理（v3.3.0）
----------------
· 点行尾 ↓ 开始下载，右下角会自动弹出「下载管理」面板（工具栏的 ↓ 图标也能打开）。
· 每条任务显示：歌名、进度百分比、已下/总大小、实时速度、进度条。
· 暂停：立刻停，已下的部分留着；点「继续」从断点续传（不会重下）。
  暂停中的任务会写进 data\downloads.json，关掉程序再开还在，位置、进度都记得。
· 删除：正在下的会中断并删掉 .part 残片；已完成的只是从列表移除，**文件不会删**。
· 「清除已完成」一键清掉列表里所有已完成/失败的记录。
· 下载按当前音质设置走：选「母带」时一首可能 200MB，选「无损优先」通常 25~70MB。
· 播放时会先解析地址：万一这个源放不了，会自动去别的源找同一首歌，
  底部状态栏会写明「已自动换源：酷我 · 320k」这类信息。

音质
----
· 默认「无损优先」：能拿到 FLAC 就用 FLAC（状态栏会写「无损 FLAC 2832k」），
  拿不到自动降级到 320k / 128k，不会因为没无损就放不出来。
· 下拉框还能选「音质优先（320k）」和「省流量（128k）」。
· 列表里的「音质」列会逐行探测：搜完约 2~4 秒后，能拿 flac 的行会变绿显示「无损」或「高解析」，
  鼠标停上去能看到码率和文件大小（母带档动辄 150~200MB）。只显示 128k/320k 的行就是没有 flac。
  探测只取 2 字节算大小，不下载；解析结果会缓存，点播放时几乎立刻出声。
· 无损怎么来的（v3.2 起）：主走「青听网关」——用酷我/QQ/酷狗/网易自己的歌曲 ID
  直接换 flac，四家都通，还能要「母带」档；拿不到再退回原来那条「网易 id 换 flac」的免费线路。
  两次都失败才降级到 320k / 128k，绝不会拿翻唱冒充原唱。
· 实测 6 首（含周杰伦《晴天》、Beyond《海阔天空》）：6 首全部拿到 FLAC，单首 26~138MB，
  解析 0.5~5 秒。周杰伦那批以前只能 320k，现在也有无损了。
· 母带档（下拉框选「母带（最大）」）能到 4800kbps、单首可上百 MB；同一首的「母带」有时
  平台只给 800k 出头的文件，所以状态栏按真实码率写「无损」或「高解析」，不糊弄。
· 青听网关是别人的中转服务，随时可能停：关掉或它挂了会自动退回免费线路，
  设置面板下半部分有开关和「测试线路」按钮。
· 第一次播放无损要等 0.5~5 秒解析；20 分钟内重放会复用结果。
· 主源给的码率低于 96k 时，会自动去别的源找更好的版本（比如 48k → 128k）。

缓存（v3.1.0）
--------------
· 播放过的在线音乐会顺手存到本地，下次再放同一首不用再等解析、也不费流量。
· 无损一首几十上百 MB，所以默认上限 4 GB；超了自动删最久没放过的那些。
· 位置和上限都在「在线搜索」页右上角那个圆柱图标里改：
  「播放时自动缓存」开关、缓存目录（可以改到别的盘）、上限（1~16 GB / 不限）、
  「清理缓存」一键清空（面板上会显示当前共几首、占多少）。
· 只有**完整听完**一首才会留下缓存；中途切歌 / 拖进度条不会留残片。

高级音源（v3.1.1，可选）
------------------------
· 为什么要填：无损现在主要靠「网易 id 换 flac」，而网易没有周杰伦这类歌的版权。
  填了高级音源，QQ 音乐和酷狗的歌也能直接拿无损——这是目前提升覆盖率最有效的一步。
· 怎么弄：在线搜索页右上角圆柱图标 → 面板下半部分「高级音源」。
  点「去注册」会打开 ChKSz API 的注册页，邮箱注册（要过人机验证），
  登录后点「查看密钥」复制 apikey，回来粘进输入框点「保存并验证」。
· 额度：据其文档每日免费 50 次。所以只在「QQ/酷狗的歌」上用它；
  网易的歌仍然走免费通道，不占额度。
· 隐私：key 只存在本机 data\settings.json，不上传到任何地方。
· 不填也完全能用，只是 QQ/酷狗 的歌大概率只能到 320k。

下载
----
· 默认目录：C://Users//<你的用户名>//Music//猪专属下载，在网页面板右侧文件夹图标可改。
· 文件名格式「歌手 - 歌名.mp3」，重名自动加 (2)(3)。
· 下载完成后文件不会自动进曲库——想把下载的歌并入本地库，去「音乐文件夹」里
  把下载目录加进去再扫一次即可。

必须说清楚的局限（别抱不切实际的期待）
--------------------------------------
· 这是第三方公开接口，不是官方授权：热门新歌、独占版权的歌经常只有 30 秒试听，
  甚至所有源都拿不到地址（会提示「各音源都没有可用的地址」）。
· 实测 32 首不同年代/冷热的歌：29 首拿到完整版（91%），2 首只有试听片段
  （青花瓷、白月光与朱砂痣——这几家确实把原唱锁在 VIP 里），1 首搜不到。
  平均解析约 1.5 秒。不同歌差别很大，冷门歌/独立音乐反而更容易拿到完整版。
· 无损不是百分百：取决于这首歌在对应平台有没有 flac 资源 + 中转服务当时的状态，
  拿不到就老实降级到 320k/128k，状态栏会如实写当前是什么音质。
· 咪咕、B站试过：咪咕试听要登录，B站取流有风控，都没接。
· 接口随时可能失效。真失效了不是软件坏了，需要更新音源实现。

一、怎么启动
------------
· 双击桌面上的「猪专属播放器」快捷方式即可。
· 如果快捷方式被删了：进本文件夹（D:\猪专属播放器联网版），双击「启动播放器.vbs」。
· 不要直接双击「猪专属播放器.exe」——本机 Windows 环境下 Chromium 沙箱起不来，
  直接双击会“闪一下就没了”。启动器会自动补上 --no-sandbox 参数（只关闭渲染沙箱，
  程序不联网，只读你本机的音乐文件）。
  联网版需要联网才能搜歌，但仍不需要管理员权限。

二、为什么放在 D:\猪专属播放器
------------------------------
· 之前放在 D:\文档\deepseek-harness\default-workspace\ 下面，双击会弹「安全警告：
  未知发布者」。原因是那个工作区目录被设成了「低完整性级别」，Windows 认为里面的
  程序不可信。换任何程序进去都会弹，不是本程序的问题。
· 所以成品挪到了 D:\猪专属播放器，放在这一层就正常了，不再弹窗。
· 如果想换位置：整个文件夹一起拷走就行（绿色便携），但别放回那个 default-workspace
  目录，也别放在 C:\Windows、C:\Program Files 这类需要管理员权限的地方。

三、第一次用
------------
· 默认曲库目录是 D:\音乐，首次启动会自动扫描一次。
· 支持格式：flac / mp3 / m4a / aac / wav / ogg / opus / ape / wma / aiff / dsf / dff / mka。
· 歌词：与音频同名、扩展名 .lrc 的文件会被自动读取（UTF-8 / GBK 都能识别）。
  文件名没带歌手、或者写成「歌手 - 歌名」的情况，会用 LRC 里的 [ti:] / [ar:] 校正。
  音频文件里内嵌的歌词标签（FLAC 的 LYRICS、MP3 的 USLT）也会读。两份同时存在时
  **比修改时间，谁新用谁**：你用 Mp3tag 之类改标签，音频文件会变新，就用内嵌的；
  直接改 .lrc 文件，.lrc 变新，就用外置的。不用手动切。
  改完保存后播放器 1 秒内自动刷新，不用切歌也不用重启。
· 封面：优先读音频内嵌封面；没有内嵌时找同名图片，或「专辑__ALBUM.jpg」
  「歌手__ARTIST.jpg」这类命名。

四、音乐文件夹管理（v1.1 新增）
-------------------------------
点右上角「音乐文件夹与扫描」按钮（文件夹图标）打开管理弹窗：
· 上方列出当前所有曲库目录，每个目录右侧的 × 可以移除。
· 点「+ 添加文件夹」可以再选一个目录加入（支持一次多选，会自动去重）。
· 确认无误后点「保存并扫描」，会立刻按新目录重建曲库，弹窗自动关闭。
· 支持多个文件夹同时作为曲库，子文件夹会被递归扫描。
· 改目录不会丢收藏/歌单：它们按歌曲记录，重新扫到同一首就还在。

五、界面
--------
左栏：全部音乐 / 我的收藏 / 最近播放 / 专辑 / 我的歌单（点 + 新建）。
中间：歌曲列表，点表头可排序，双击表头恢复默认顺序，右键有菜单。
右侧：封面 + 同步滚动的歌词，点歌词任意一行可跳转到那一句。
底部：播放条（进度、上一首/播放/下一首、音量、播放模式）。
搜索：右上角搜索框，歌名/歌手/专辑/文件名都能搜，**也支持拼音**——
      输 zjl 或 zhoujielun 都能找到周杰伦（v1.6 新增）。
拖拽：按住歌曲左侧的序号，拖到左边的歌单上就能加进歌单；
      播放队列面板里的条目可以上下拖动排序（v1.6 新增）。
多选：Ctrl + 点击 逐个选，Shift + 点击 连选一段，Ctrl + A 全选，Esc 取消。
      选中后列表上方会浮现工具条：播放 / 收藏 / 加入歌单 / 取消选择；
      右键也能对这一批「加入歌单 / 加入收藏 / 从歌单移除」，
      按住其中任意一行的序号拖进歌单也是整批带走（v1.7 新增，v2.6 加工具条）。
      右键菜单的「加入歌单」子菜单：点一下就能展开（v2.6 修复：以前
      必须悬停，点一下整个菜单就消失了），歌单很多时可滚动，靠屏幕
      右缘时自动向左弹出。

六、快捷键
----------
空格            播放 / 暂停
← / →           快退 / 快进 5 秒（按住 Shift 是上一首 / 下一首）
↑ / ↓           音量 +/-
M               静音
L               收藏当前歌曲
Ctrl + F        搜索框
Esc             关闭右键菜单 / 关闭弹窗
（以上在窗口内有效）

另外注册了系统级媒体键：键盘上的播放/暂停、上一首、下一首、停止键，以及
Ctrl+Alt+空格（播放暂停）、Ctrl+Alt+←/→（切歌）、Ctrl+Alt+↑/↓（音量）、
Ctrl+Alt+D（桌面歌词）、Ctrl+Alt+M（迷你模式），窗口在后台时也能用。

七、播放模式
------------
点底部那个循环图标切换：列表循环 → 单曲循环 → 随机播放 → 顺序播放。
切歌和暂停都有 0.35 秒淡入淡出（可在 data\settings.json 改 fadeMs）。

八、音量均衡（v1.2 新增）
------------------------
· 播放条右侧的均衡器图标（三条竖线）是音量均衡开关。打开后，各首歌会自动调整到
  差不多的响度，不再出现「这首歌特别小、下一首突然炸」的情况。
· 第一次使用：右键均衡器按钮 →「分析曲库响度」。程序会把曲库里的歌逐首解码分析
  （71 首大约 1 分钟），分析结果保存在本地，之后随时开关。
· 右键菜单里还能改「目标响度」（默认 -16 LUFS，数字越小整体越响）和清除分析数据。
· 某首歌觉得还是太轻/太响：在歌曲列表里右键它 →「音量增益」，手动 -6 ~ +6 dB。
  手动设置永远生效（即使没开均衡开关），选「0 dB（重置）」可还原。
· 说明：分析在播放的同时也能跑；ape / wma / dsf 这类格式系统解码不了会自动跳过。

九、桌面歌词（v1.2 新增）
------------------------
· 点标题栏的「桌面歌词」按钮（或按 Ctrl+Alt+D、托盘菜单里选）打开：一个透明的
  悬浮窗，始终显示在屏幕最前面，跟着播放进度滚动当前句，下面带一句预览。
· 鼠标移上去会浮出控制条：🔒 锁定 / A- A+ 字号 / 🎨 换颜色 / ✕ 关闭。
· 锁定后窗口完全不吃鼠标（可以点它下面的东西）；解锁点主窗口标题栏那个按钮即可。
· 位置拖一拖就行，窗口大小也能拉；位置、字号、颜色都会记住，下次打开还是老样子。
· 关掉主程序时桌面歌词会一起关掉（不会有孤零零的歌词窗留在桌面上）；
  下次启动如果之前开着，会自动恢复。

十、均衡器与频谱（v1.3 新增）
----------------------------
· 播放条右侧的滑条图标（三条横杠加旋钮）打开均衡器面板，靠右悬浮在播放条上方。
· 10 段 EQ：31 / 62 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz，范围 ±12dB。
  拖动滑块即时生效；双击某个滑块把它归零。
· 8 个预设：平直 / 流行 / 摇滚 / 古典 / 爵士 / 低音增强 / 人声 / 电子。点一下就套用。
· 面板右上角「已开启 / 已关闭」是总开关。关闭后所有频段归零（原声），但设置会记住。
· 动任意滑块会自动打开均衡器，不需要先按开关。
· 为了避免加强低音后爆音，程序会自动把整体音量往回收（内部自动前级，不需要手动调）。
· 频谱：右侧歌词面板封面下面那条跳动的柱状图，就是当前音乐的实时频谱，
  跟着节拍动，峰值会缓慢下落。不需要可以忽略，不影响任何功能。

十一、迷你模式（v1.4 新增）
--------------------------
· 进入：点标题栏右侧的「迷你模式」按钮（一个方框里套小方框的图标），或者在任何
  界面下按 Ctrl+Alt+M，托盘图标右键菜单里也有「迷你模式」。
· 窗口会缩成一张竖向小卡片（约 320×420），里面只有：封面、歌名、歌手、当前一句
  歌词、进度条、上一首/播放/下一首、播放模式、收藏。窗口能拖到屏幕任意角落。
· 播放不会中断，也不会重开窗口——迷你模式只是把同一个窗口变小、换一套界面，
  所以不会出现「切来切去歌断了」的情况。
· 返回完整模式：点卡片右上角的放大按钮，或再按一次 Ctrl+Alt+M，
  也可以直接双击封面/歌名那一块。窗口会回到你进迷你之前的尺寸和位置
  （如果当时是最大化，回来也还是最大化）。
· 卡片大小可以自己拉（最小约 300×360），下次进迷你还是这个尺寸；
  迷你卡片里的进度条同样可以拖动跳转。
· 关掉程序时如果正处在迷你模式，下次启动还是迷你卡片。

十二、数据存在哪
--------------
全部在本文件夹的 data 子目录里，纯绿色便携版，拷走整个文件夹就能带走配置：
  data\settings.json   设置、收藏、播放历史、歌单、播放次数
  data\library.json    曲库缓存（文件名、元数据、时长、封面路径）
  data\covers\         从音频里提取出来的封面图
  data\lx-player.log   启动日志（出问题时看这个）

十三、常见问题
------------
Q: 双击快捷方式弹「安全警告：未知发布者」
A: v1.1.2 已解决。旧版成品放在 default-workspace 那个目录里，该目录是「低完整性
   级别」，Windows 对里面的程序一律提示。现在成品在 D:\猪专属播放器，不会再弹。

Q: 双击没反应 / 闪一下就退出
A: 用「启动播放器.vbs」或桌面快捷方式启动。直接跑 猪专属播放器.exe 会因为沙箱
   问题秒退。

Q: 换音乐目录 / 多加几个文件夹
A: 点右上角的文件夹图标，在弹窗里增删目录后点「保存并扫描」。

Q: 扫描完歌曲数不对
A: 点右上角文件夹图标重新扫描；只认上面列出的音频扩展名，子文件夹也会递归扫描。

Q: 歌词不滚动 / 对不上
A: 右下的两个小箭头可以调歌词偏移（每次 0.5 秒），A- / A+ 调字号。
   v1.1.2 已修：旧版歌词面板设了「平滑滚动」，高亮每 0.2 秒切一次会把动画反复打断，
   结果卡在半路不回来。现已改为瞬时定位，当前句稳定停在面板正中；
   只有歌曲开头几句和结尾几句滚到边界时无法居中，属正常。

Q: 封面变成空白 / 不显示
A: v1.1.2 已修。旧版把封面图路径按「绝对路径」记在缓存里，整个文件夹一搬家就全部
   失效。现在改成记相对文件名，整个文件夹拷到哪都能正常显示。

Q: 点了歌名却切不过去 / 还是上一首
A: v1.1 已修。旧版在播放中点击同列表的其它歌曲时，会把播放位置强行拉回当前歌曲。

Q: 歌词显示的是别的歌
A: v1.1 已修。旧版快速连续切歌时，上一首的歌词可能晚到并覆盖新歌的歌词。

Q: 改了歌词，播放器里还是旧的
A: 先确认改的是哪一层。播放器会同时看外置 .lrc 和音频内嵌的歌词标签，两者取修改时间
   较新的那份。如果你在标签编辑器里改的是内嵌标签却看不到变化，检查这个文件的
   「修改时间」是否真的更新了（有些工具改完不更新文件时间）。v3.3.4 起改完保存
   1 秒内自动刷新，不用重启。

Q: 每次启动都自动重新扫描曲库？
A: 默认不开。想开的话：先把全部程序关掉，再用记事本打开 data\settings.json，把
   "settings" 里的 "autoScanOnStart" 从 false 改成 true（注意不要动其它内容），
   保存后重新启动。开着的代价是每次启动多等几秒；关掉它还是老样子。
   v1.3.1 已接线：这个开关以前只是个摆设，现在真的会生效。

Q: 想让点 × 时最小化到托盘（不退出）
A: v2.4 起点 × 会弹窗问你「最小化到托盘还是直接退出」，勾选「不再提示」后按这次的
   选择执行，以后不再问。想改回来：托盘图标右键 → 「关闭时询问」重新勾上，
   或直接勾/取消「关闭时最小化到托盘」。

Q: 想换背景色 / 主题色
A: 目前是固定的深色主题（主题色 #31c27c），要改可以编辑源码里的 css 后重新打包。

Q: 迷你模式怎么回不到原来的大小
A: 正常情况点放大按钮（或 Ctrl+Alt+M、双击封面）就会回到进迷你前的尺寸位置。
   如果之前手动拉过迷你卡片，回来的还是完整模式原来那个尺寸——两者分别记忆。

Q: Ctrl+Alt+M 没反应
A: 这个组合键可能被别的软件占用了（例如某些截图/录屏工具）。改用标题栏的迷你
   按钮，或者托盘右键菜单里的「迷你模式」即可。

Q: 桌面歌词关掉再打开，歌词要等一下（或暂停一下）才出来
A: v1.4.1 已修。旧版歌词窗口是异步加载的，打开那一瞬间的歌词会被丢掉，而程序
   又按「内容没变就不发」去重，所以只能等下一句切歌时才出现（暂停会让播放状态
   变化，恰好触发一次重发）。现在主进程会记住当前歌词行，窗口一就绪立刻补上。

Q: 鼠标移到桌面歌词上会闪一下
A: v1.4.2 已修。旧版悬停时控制条会挤进布局里，把歌词整体往下推 16px（移开又弹
   回去），看起来就是闪；另外背景颜色也会随悬停变化，整窗重绘更容易看出来。
   现在控制条是浮在上方的一条小面板（淡入淡出、不占位），背景不再变化，
   歌词位置全程不动。

Q: 开了播放器以后，浏览器/微信/视频都没有声音了
A: 说明你开着「独占输出」，它按设计独占了声卡（v1.5 新增功能）。点标题栏那个
   波形按钮关掉即可；也可以先暂停播放，声卡就还给其他程序了。

十五、独占输出（位完美，v1.5 新增）
----------------------------------
先说结论：这个功能只影响"数字信号到声卡这一段"，不改变文件本身。

· 开关在哪：标题栏右侧那个"波形"图标（喇叭上面有高低柱子），右键不用，
  单击即可开关。第一次开启会弹一个确认框，把下面这些副作用讲清楚。
· 开启后：改用 mpv + Windows WASAPI 独占输出。声卡会按文件的**原生采样率、
  原生位深**直接接收数据——44.1k/16bit 的歌就是 44100Hz/16bit 送出去，
  96k 的歌就是 96000Hz 送出去，中间不做重采样、不做软件音量（音量 100% 时）。
· 怎么看是不是真的位完美：播放条右侧会出现一个小标签，
  绿色「位完美 · 48k/32bit」= 正按原生格式直出；
  琥珀色「非位完美 · 音量 82%」= 你把音量拖下来了，软件在改样本值；
  琥珀色「已重采样」= 声卡不接受这个采样率，程序只能重采样；
  琥珀色「已回退共享」= 独占打不开（被别的程序占用/驱动不支持），已自动退回普通输出。
· 开启独占期间，**其他程序会没有声音**（浏览器、微信、视频都静音）——这是
  WASAPI 独占的固有行为，不是故障。关掉独占或暂停播放后恢复正常。
· 独占模式下，均衡器、音量均衡、手动音量增益、实时频谱会自动禁用
  （任何软件处理都会破坏位完美）。播放模式、歌词、桌面歌词、迷你模式一切照常。
· 切换开关时界面会重新加载一次，播放会中断，但队列、进度、播放模式都会恢复。
· 如果想在独占模式下调音量：拖音量条可以（会显示"非位完美"），
  或者在功放/系统音量上做，播放器保持 100% 才是原样输出。
· 指定输出设备（v1.6 新增，v2.3 升级为正式面板）：如果你接了 USB DAC / 外置声卡，
  默认设备未必是它。**左键点**播放条右侧那个位完美标签（独占开着时），或**右键**
  标题栏的波形按钮，会弹出「独占输出」面板，列出所有 WASAPI 输出设备，
  点一个即可，点「刷新」重新检测。播放中切换会自动重启引擎、回到原位置并
  继续播放（v2.5 修复：以前切完设备音乐会停住不动）。选「跟随系统默认设备」可以还原。
· 高精度音量（v2.5 新增）：同一个面板下半部分，滑条 0.1 步进、实时显示 dB 换算
  （如 37.5% · -8.5 dB），底层走 mpv 浮点音量，比主界面的整数音量条细得多。
  100 = 位完美基准；小于 100 时位完美标签会变成琥珀色（软件在改样本值，属正常现象）。
  切设备 / 重启引擎后音量不再被重置回 100，会保持你设的值。

十六、v1.6 新增的几件事
------------------------
【拼音搜索】搜索框支持全拼与首字母：zjl / zhoujielun / 周杰伦 都能出结果。
   拼音是在扫描曲库时算好存起来的，搜起来不卡。改了歌名要重新扫描才会更新。

【歌单文件（m3u / m3u8）】
   · 重命名（v2.7 新增）：右键歌单 → 「重命名」，或直接双击歌单名。
     弹窗里输入新名字，回车或点「确定」生效，Esc 取消。
   · 导出：在左边「我的歌单」里右键某个歌单 → 「导出为 m3u…」。
     默认存成相对路径（歌单和音乐放在一起时，整个文件夹搬走也不会失效）；
     跨盘保存时会自动写成完整路径。
   · 导入：点「我的歌单」标题右边那个文件夹图标 → 选一个 .m3u / .m3u8。
     程序会按路径去曲库里找对应的歌，找到的直接建成新歌单；
     不在曲库里的条目会被跳过，并在提示里告诉你有几条没匹配上。

【断点续播】只对**超过 10 分钟**的音轨生效（有声书、讲座、现场、交响乐）。
   听到一半切走或关掉程序，下次再点这首会从断点继续，屏幕上会提示
   「已从 XX:XX 继续播放」。普通歌曲不记位置，避免点播放却从中间开始。
   快听完（剩 20 秒内）会清掉断点，下次从头放。

【拖拽】队列面板里拖动条目可以排序（正在播的那首不会因为拖动而串位）；
   歌曲列表里按住序号拖到左边歌单上，直接加进那个歌单。

【任务栏按钮】鼠标悬停在任务栏图标上，会出现 上一首 / 播放暂停 / 下一首 三个按钮。
   注意：这只是任务栏的缩略图工具栏，**不是**系统媒体控制中心，
   所以系统音量浮层、锁屏界面里暂时还看不到歌名和封面。

【看不见的修复】
   · 以前拔掉移动硬盘（或网络盘掉线）再点扫描，库里这些歌会被当成"已删除"清空，
     重连后要重新扫很久。现在检测到目录不可访问会跳过清理，只提示「N 个目录不可访问」。
   · 个别文件解析失败（例如驱动不支持的 wma），以前会悄悄从列表里消失；
     现在扫描结束会告诉你有几个解析失败。
   · 程序被任务管理器强杀后，后台可能残留 mpv 进程占着声卡（表现为别的程序全没声音）。
     现在下次启动会自动清掉残留的 mpv。
   · data 文件夹里的浏览器缓存会自动清理，不会越用越大。

十七、v1.7 新增的几件事
------------------------
【歌词偏移按歌记忆】歌词面板上的「提前 / 延后 0.5 秒」现在只改**当前这首**。
   以前是一个全局值，调好一首会把别的歌一起带偏；现在每首歌各记各的。
   （没单独调过的歌仍用全局默认值。）

【最常播放】左侧新增。只列有播放记录的曲目，按播放次数从多到少排，
   每行标题后面那个绿色小数字就是播放次数。播放计数在「播放到 30 秒或一半」时加一。

【文件夹视图】左侧新增。按曲目所在目录分组显示，点进去就是这个目录下的歌。
   标签不全、专辑名乱七八糟的时候，按文件夹找最靠谱。
   如果你的歌全都平铺在一个目录里，这里只会有一个卡片，属于正常。

【自动监视音乐文件夹】往音乐文件夹里丢新歌 / 删歌，8 秒后列表自动更新，不用再点扫描。
   之所以等 8 秒：拷一整张专辑会触发几十次文件变化，攒一次扫完更省事。
   不想让它自动扫，可以在「音乐文件夹」弹窗里把勾去掉。
   （只认音频、.lrc、封面图片的变动，其他文件动了不会触发。）

【睡眠定时】（v2.2 起改在软件内部设置，不再放托盘菜单）
   播放条右下角、均衡器按钮左边的「时钟」图标 → 选 15 / 30 / 60 / 90 分钟，或「关闭」取消。
   面板里会实时显示剩余倒计时；到点会按正常的淡出效果暂停，不是硬切。
   定时进行中播放条上的时钟图标会变成绿色。

十八、诊断面板（v1.8 新增）
------------------------
标题栏最右边、最小化按钮左边的「虫子」图标，点开就是诊断面板，分三个标签：

【解析失败】
   列出曲库里所有“有问题”的文件，分四类：
     · 无法解析——文件头都读不出来，这类根本没进曲库（以前就是它们让列表莫名其妙少歌）；
     · 标签缺失——能播，但读不出歌名/歌手/封面，界面上显示的是文件名；
     · 时长未知——解析“成功”但读不出时长，多半是文件损坏或格式不被支持；
     · 读不到——扫描时文件被占用或没权限。
   每条都带完整路径、错误原因和最后一次失败时间；右边的文件夹按钮能直接定位到文件。
   文件已经被删/移走的条目会标灰并写「文件已不在」。

【mpv 日志】
   只跟「独占输出」有关。上面一行是引擎状态（运行中/未运行、独占还是共享）；
   默认「实时」模式显示本次运行期间的事件：引擎启动结果、实际输出参数
   （audio-out-params，判断是否位完美的第一手证据）、播放失败原因、回退共享、
   引擎退出码等。切到「日志文件」能看到 data\lx-player.log 的尾部（含启动阶段信息）。
   注意：平时用普通输出（没开独占）时，这里本来就是空的，属正常。

【环境】
   版本、Electron/Chromium/Node 版本、数据目录、日志文件位置、mpv 引擎是否存在、
   引擎状态、独占设置、输出设备、曲库规模、音乐目录、是否正在扫描。

底部三个按钮：
   · 复制——把当前标签的内容整段复制到剪贴板（贴给别人看最省事）；
   · 打开日志文件——在资源管理器里定位 data\lx-player.log；
   · 重新扫描——关掉面板并立即重扫曲库。

失败明细单独存在 data\parse-failures.json。点「清空记录」只是把这份清单清掉，
文件本身没动；下次扫描如果文件还是坏的，会重新记上。

十九、v1.9 新增：最近添加 + 音质列
------------------------
【最近添加】左侧新增，按"入库时间"倒序，新扫进来的歌永远排最上面。
   侧栏后面的数字是**最近 7 天新增**的条数（不是这个视图的总数）；
   标题下面会写「共 N 首 · 最近 7 天新增 M 首」。
   入库时间只认第一次：重新解析标签、换封面、升级程序都不会把老歌顶到最前面。
   老曲库第一次升级时会用文件的修改时间兜底，所以显示的是"这批文件大致什么时候来的"。

【音质列】列表里新增一列，无损显示「位深/采样率」（如 24/96 = 24bit 96kHz），
   有损显示码率（如 320k）。24bit 以上或采样率高于 48kHz 的会亮一档颜色，
   一眼能看出哪些是真高清。想按音质排：点表头「音质」，**第一下就是降序**
   （最好的在最上面），再点一次升序，第三次恢复默认顺序。
   鼠标停在这一列上会显示完整参数（位深、采样率、编码、码率、有无损）。

【表头排序统一成三态】点一下按该列排序，点第二下反向，点第三下恢复默认
   （以前第三个状态是空的，只能靠双击表头才能回默认）。

二十、v2.0 新增：内嵌歌词 / ReplayGain / DSD / 封面不再落盘
------------------------
【内嵌歌词】以前只认与音频同名的 .lrc 文件。现在如果没有 .lrc，会读音频标签里
   自带的歌词（FLAC 的 LYRICS、MP3 的 USLT），带时间轴的就按时间滚动，纯文本的
   就静态显示。**外置 .lrc 永远优先**，方便你随时改词。
   读出来的内嵌歌词会存成 data\lyrics\<id>.lrc，想让它重新从标签读取，删掉这个
   文件再扫一次即可；曲目被移除时该文件会自动清理。

【ReplayGain 标签】音量均衡以前只有"逐首分析响度"一条路，整库要跑好几分钟。
   现在扫描时顺带读文件自带的 ReplayGain 标签（多数正经 FLAC 都有）：
     优先级：手动微调 > 自己分析的响度 > ReplayGain 标签 > 不调整
   自己分析的排在前面的原因是——分析是按你设的目标响度算的，标签是别人写的、
   目标响度不一定和你一致。带标签的曲目在"分析响度"时会被自动跳过（省时间），
   想覆盖就先用右键菜单清掉分析数据。

【DSD 标注】dsf / dff 文件在"音质"列显示 DSD64 / DSD128 / DSD256，鼠标悬停能看到
   实际采样率（2.8224 MHz 等）。**普通输出（Chromium）没有 DSD 解码器**，
   点播这类文件不会再只报一句"无法播放"，而是明确提示"需要独占输出"并告诉你去
   点标题栏的波形按钮；在独占模式下由 mpv 解码后输出。

【封面不再落盘】以前每首内嵌封面都会往 data\covers 写一个文件（上千首就是上千个
   小文件）。现在封面直接从音频里按需解出来，缓存放在内存里，走内部的 lxcover://
   协议；升级后第一次启动会自动清掉旧的封面缓存文件（只删 32 位哈希命名的图片，
   不会碰你自己的图）。与音频同目录的 cover.jpg / 专辑图仍然优先使用。
   副作用：data\covers 目录会一直是空的，这是正常的。

二十一、v2.1 新增：A-B 循环 / 播完关机 / 设备热插拔 / 锁屏控制
------------------------
【A-B 循环】播放条右侧、队列按钮旁边那个「A-B」小按钮。点一下设 A 点（按钮变 A-），
   播到终点再点一下设 B 点开始循环（按钮变绿、进度条上出现两个绿色刻度），
   再点一下取消。换歌会自动清掉——A-B 是"这一首之内"的事。
   · 普通输出：每 250ms 比较一次进度再回跳，误差约 0.1 秒；
   · 独占输出：直接交给 mpv 的 ab-loop，循环点精确到采样，听不出接缝。
   B 点至少要比 A 点晚 1 秒，否则会提示。（拖动进度条不影响已设的 A/B 时间点。）

【播完关机】托盘右键 → 播放结束后 → 不处理 / 关机 / 休眠 / 关闭播放器。
   判定时刻：顺序模式放到队列最后一首结束，或列表循环绕完一圈回到第一首。
   触发后有 **15 秒倒计时**，屏幕上会写着还剩几秒：
     · 按 Esc 取消；
     · 或托盘菜单里点「⚠ 取消关机 / 休眠」。
   这是**一次性**的：执行过一次就自动回到「不处理」，不会第二次自动关机。
   和「睡眠定时」是两件事：那个是到点暂停，这个看播放进度。

【设备热插拔】独占输出时，如果选定的声卡（USB DAC）被拔掉，以前是静默失效、
   表现为"没声音也不知道为什么"。现在每 8 秒核对一次设备列表：
     · 设备消失 → 提示一次，并自动切回系统默认设备，播放不中断；
     · 设备插回 → 提示一次，并自动切回原来那台。
   （只在本次运行里记着"刚才拔掉的是哪台"，重启后不猜。）

【锁屏 / 音量浮层显示歌名】Windows 的音量浮层、锁屏界面、键盘上的播放/上一首/下一首
   现在会显示歌名、歌手、专辑和封面，按钮也能直接控制播放。
   实现走的是 Chromium 自带的 Media Session，没有引入原生模块。
   · 普通输出：必定生效；
   · 独占输出：声音走 mpv，页面里没有播放中的音频，所以额外挂了一条听不见的静音流
     来维持这个会话。如果某些机器上浮层没出现，就是这条流被系统拦了，
     属于已知限制（不影响播放本身）。
