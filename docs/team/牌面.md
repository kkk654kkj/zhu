# 牌面（唯一派工单，入库受 git 仲裁）

**规则只有三条**：

1. 领牌 = 把牌从「待领」移到「在做」，在「领牌记录」加一行，然后 `git commit -m "board: 领 <牌> by <窗口代号>"`。**先提交成功者得牌**；rebase 时看到牌已被别人领走，立刻换下一张，别抢。
2. 收牌**不改这个文件**。完成态由 tag 表达：`gate/<牌>-pass` 存在即完成。
3. 加牌 = 在「待领」加一行，同一笔 commit 里写清验收口径。谁都能加，必须署名。

机制说明在 `D:\猪专属播放器项目\团队协作\`（人读，不入库）；卡口判据见 `20-卡口.md`。
